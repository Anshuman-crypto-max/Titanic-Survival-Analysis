# Titanic Survival Analysis

## Project Overview

This project analyzes the Titanic dataset to identify factors that influenced passenger survival.

## Tools Used

* Python
* Pandas
* NumPy
* Matplotlib
* Jupyter Notebook

## Tasks Performed

* Data Cleaning
* Handling Missing Values
* Exploratory Data Analysis (EDA)
* Data Visualization

## Key Findings

* Female passengers had a higher survival rate than male passengers.
* First-class passengers survived more frequently than passengers in lower classes.
* Passenger age influenced survival probability.
